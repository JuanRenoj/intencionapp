# Sistema de Registro de Intenciones de Misa

Sistema de escritorio gratuito para registrar, organizar y consultar las intenciones de los fieles para las misas. Desarrollado para facilitar la labor de secretarios y coordinadores parroquiales, evitando el registro manual y la dispersión de archivos en Excel.

---

## 📋 Descripción

El registro de intenciones de misa suele hacerse a mano o en múltiples archivos de Excel, lo que consume tiempo, genera desorden y dificulta la consulta posterior. Este sistema centraliza esa información en una sola aplicación, permitiendo:

- Registrar intenciones con los datos del fiel y la intención.
- Organizar por fecha, tipo de misa o nombre.
- Consultar y filtrar intenciones registradas.
- Historial de las ofrendas de las intenciones por misas.
- Definir el valor de la ofrenda por intención.
- Evitar el manejo de varios archivos y el trabajo manual repetitivo.

**Es completamente gratuito y sin fines de lucro.** Fue desarrollado como aporte a la labor pastoral.

---

## ✨ Características principales

- ✅ Registro rápido de intenciones de misa.
- ✅ Organización por fecha, hora y tipo de intención.
- ✅ Búsqueda y filtrado de registros.
- ✅ Interfaz sencilla, pensada para usuarios sin conocimientos técnicos.
- ✅ Funciona sin conexión a internet.
- ✅ Datos almacenados localmente (no requiere servidor).

## 💻 Requisitos del sistema

## 📥 Descarga e instalación

1. Ve a la sección **[Releases](../../releases)** de este repositorio.
2. Descarga el archivo ejecutable más reciente: `intencion-1.0.1.Setup.exe`
3. Ejecuta el archivo y sigue las instrucciones en pantalla.
4. No requiere instalación adicional ni permisos de administrador.

> **Nota:** Si Windows muestra una advertencia de seguridad al ejecutar el archivo, es normal en aplicaciones nuevas sin firma digital. Puedes continuar con la ejecución.

## 🔒 Privacidad

Este sistema **no recopila datos personales** ni envía información a internet. Todos los registros se guardan únicamente en el equipo donde se ejecuta la aplicación.
